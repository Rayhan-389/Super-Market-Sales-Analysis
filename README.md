# Supermarket Sales Data Analysis

## 📌 Project Overview
This project focuses on analyzing supermarket sales data to identify customer purchasing behavior, sales performance, product trends, and business insights. The analysis was conducted using Python in a Jupyter Notebook environment with the help of data analysis and visualization libraries.

The project helps understand:
- Customer buying patterns
- Product line performance
- Branch-wise sales comparison
- Payment method trends
- Revenue and profit insights

---

# 📊 Objectives

- Analyze supermarket sales trends
- Identify top-selling product lines
- Compare sales across different branches
- Analyze customer purchasing behavior
- Visualize revenue and rating patterns
